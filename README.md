# 万神纪 · 世界神话图谱

一个中文神话学习网站，以大陆地图和可旋转地球为入口，按传统浏览世界观、历史联系、人物分级、关系图、故事、引句与图像。

玛雅与阿兹特克分别成卷；克苏鲁作为现代文学专题单列，持续标明虚构创作与历史宗教传统的区别。主体和事件详情页提供图像、原典定位和短引句；关系图使用有明确对应关系的图像作为头像，合刻图仅在头像中裁切。

每卷新增「法宝与物件」目录，可按重要性、类型、原典与关键词检索。物件与人物、事件双向连接，可收藏到学习书签。关系图可选择体系分组并打开物件节点：圆形为人物或生灵，方形为物件。物件关联包括制造、持有、使用、争夺与作用对象；详细语义在各条叙事和出处中说明。坐骑作为生灵主体收录，阵法与随身器物区分。

当前内容：18 个分区、642 位主体、220 个事件、375 件物件、57 个体系分组；384 个独立本地图像文件。共有 1,272 条逐项出处定位。211 件物件配有图像，其中部分是明确标注的关联人物或场景参照；其余保留文字与出处。

线上地址：https://tan-t2001.github.io/myth-atlas/

## 使用

直接用浏览器打开 `dist/index.html`，即可阅读本地内容。也可在本目录执行 `python -m http.server 18765 --bind 127.0.0.1 --directory dist`，访问 `http://127.0.0.1:18765/`。

本地打包的内容与图像可离线浏览；外部原典与馆藏链接需要联网。书签、笔记和阅读进度保存在当前浏览器，支持导出 JSON，暂无跨设备同步。

## 内容组织

- `dist/data/china.json`：中国上古与先秦、汉传佛教、道教与民间信仰。
- `dist/data/core.json`：埃及、北欧、希腊罗马、希伯来传统。
- `dist/data/others.json`：专题与简明导览。
- `dist/data/images.json`：补充图像及作品年代、作者、许可、出处。
- `dist/data/bundle.js`：由上述数据生成的离线读取包。
- `dist/data/cthulhu.json`：克苏鲁现代文学专题。
- `dist/data/enrichment-*.json`：逐条主体和事件的图像、头像裁切、篇章定位及引句。
- `dist/data/expansion-*.json`：新增人物、事件、关系、物件、体系分组，以及对新旧条目的图像与原典补充。
- `research/schema.json`：内容结构。
- `research/validation-report.json`：内容完整性检查报告。

修改数据后运行 `python research/build_data.py`，合并基础资料和扩充层，检查人物关系、事件参与者、物件关联、分组成员、出处、图像路径和唯一 ID，并重新生成离线读取包。`node --check dist/app.js` 检查页面脚本语法。历史生成与界面迁移脚本是制作记录，不应用来覆盖最终数据或重复改写界面。

## GitHub Pages 发布

网站地址：https://tan-t2001.github.io/myth-atlas/

仓库地址：https://github.com/tan-t2001/myth-atlas

`.github/workflows/pages.yml` 在每次推送到 `main` 后检查内容、生成数据包，并自动发布 `dist`。仓库 Settings → Pages → Source 使用 GitHub Actions。无需任何密钥或网站账号。

修改内容后运行 `python research/build_data.py` 和 `node --check dist/app.js`，再推送到 `main`。`research/verify_media.py` 可检查本地图片，需要 Pillow。

这是独立的 GitHub 发布副本，不包含旧托管平台的身份配置和内部研究缓存。迁移其他静态托管服务时，只需上传 `dist` 目录。

## 编纂原则

地图节点代表文化区域，不宣称唯一发源点。重要性是本图谱的学习层级，不是神力排名。宗教传统、地方异文与后世小说分别讨论；神话时间与历史年代区分标注。图谱是可扩展的学习指南，未声称穷尽各传统全部材料。来源、图像署名与校正说明均可在网页中直接查看。

图片区分主体形象、叙事场景、原典文献与物件图像。没有可靠对应形象的条目保留文字；不能把同一时代的普通器物当成某件传说宝物的考古实物。公开图片以本地缓存提供，下载失败的已核实作品只列来源入口，不显示破损图片。

大陆数据：Natural Earth，公共领域。图像分别采用馆藏开放图像或公版作品，具体使用条件见每条元数据。无账号系统，无第三方分析追踪。
